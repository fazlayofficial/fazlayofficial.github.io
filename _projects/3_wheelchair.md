## Project Overview
I am currently acting as the Hardware Lead for developing an Adaptive TinyML-Based sEMG Wheelchair Control System.

### Current Progress & Goals:
* **Hardware Integration:** Designing an Adaptive TinyML framework to control a robotic wheelchair using Surface Electromyography (sEMG) signals.
* **Model Optimization:** Implementing a lightweight Convolutional Neural Network (CNN) on an ESP32 edge device, utilizing int8 quantization to reduce the model footprint by 65%.
* **Latency Reduction:** Optimizing the system for real-time inference with latency < 100ms, enabling fluid motor control for disabled users.
* **Algorithm Adaptation:** Addressing "concept drift" in bio-signals by experimenting with on-device transfer learning techniques.
